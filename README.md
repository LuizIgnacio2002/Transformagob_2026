# Transformagob_2026

Repositorio de soluciones para la **Hackatón Transformagob 2026**.

## Desafío 14 — INEN · 🧭 OncoRuta Mujer Inteligente

Sistema digital de **navegación del paciente** del Instituto Nacional de Enfermedades
Neoplásicas (INEN) para acompañar a mujeres en situación de vulnerabilidad con sospecha
de cáncer de mama o cuello uterino a través de un diagnóstico oportuno, equitativo,
inclusivo e intercultural.

➡️ **Prototipo funcional:** [`Desafío 14 - INEN/OncoRuta/`](./Desaf%C3%ADo%2014%20-%20INEN/OncoRuta/)
· Ver el [README del producto](./Desaf%C3%ADo%2014%20-%20INEN/OncoRuta/README.md) para
funcionalidades, arquitectura, credenciales de demo e instrucciones de ejecución.

**Stack:** HTML + CSS + JavaScript (ES Modules) nativo, sin dependencias. Backend simulado.

### Ejecución rápida

```bash
cd "Desafío 14 - INEN/OncoRuta"
python -m http.server 8080   # luego abrir http://localhost:8080
```
